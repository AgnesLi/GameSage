《第五人格》加页手记的求生者与监管者机制差异较大，且部分信息来自玩家社区整理，官方未发布完整技能图鉴。以下基于可查证资料整理，监管者部分因14位角色在加页手记中的差异化机制缺乏详细公开数据，主要以模式通用机制与角色选择建议为主。

# 第五人格「加页手记」全角色机制与操作攻略

> 适用模式：加页手记（摸金/搜打撤玩法）
> 说明：求生者职业为模式专属设计，与常规对局角色不同；监管者沿用常规角色但套用模式专属规则。

## 一、求生者阵营（4种职业）

求生者侧并非选择常规角色，而是从模式专属职业中选择，各职业定位差异明显。

### 1. 智者（寻宝/侦察位/刷钱）

**机制**

- **主动技能「启迪」**：冥想后标记附近容器、辞章及异象轮廓。稀世及以上品质辞章、古董柜、精致柜会产生金色指引线；未产生金线时返还75秒冷却。
- **被动「循迹」**：沿启迪指引移动时获得10%移速加成。
- **被动「急智」**：受伤时获得15%移速，持续3秒，冷却8秒。

**操作要点**

- 启迪冷却约120秒，金色指引持续约50秒，感知异象约5秒，节奏上适合“开一次、搜一片”。
- 单排独狼的首选探索职业，但打怪能力偏弱，遇到异象尽量绕行而非硬拼。
- 独狼配装建议：提灯必备，眼镜弥补磷光症视野收缩，两根针（一根强心赶路、一根回血）。

**适用人群**：喜欢探索搜刮、不想频繁战斗的玩家。

### 2. 主角（战斗/抗压位/不推荐）

**机制**

- **主动技能「奔袭」**：快速冲刺，撞到异象时根据奔袭时长造成2.2~3秒晕眩并吸引仇恨，自身获得持续8秒的50%减伤。充能3次，单次充能30秒，冲刺可随时中断保存进度。
- **被动「天生神力」**：负重减速惩罚降低至70%。
- **被动「恩赐」**：从容器开出辞章时获得10%移速，持续8秒。

**操作要点**

- 奔袭撞怪后减伤窗口是输出的安全期，趁晕眩期间蓄力攻击。
- 撞怪会消耗1层充能，不要连续空撞浪费。
- 适合走在队伍前面开路、拉异象仇恨，为智者/信使创造搜刮空间。

**适用人群**：愿意正面接敌、承担前排压力的玩家。

### 3. 信使（辅助/治疗位/组队/新手）

**机制**

- **主动技能「疗愈飞笺」**：掷出飞笺，对沿途求生者恢复30生命值；若范围内有倒地/迷失队友，飞笺会将其复活（复活后30血）并提前消失。前摇可被部分控制或传送打断。
- **被动「庇护」**：治疗效果增加50%。
- **被动「飞笺」**：首次遭受致命伤害时化作飞笺逃脱。

**操作要点**

- 组队核心，独狼不推荐——没有队友时治疗和复活价值大打折扣，打怪效率也低。
- 飞笺的复活判定范围需要预判队友倒地位置，尽量在安全掩体后使用，避免前摇被打断。
- 被动“免死一次”让信使在残局中有更高的容错，但不要因此冒进。

**适用人群**：组队玩家，尤其是双排/三排缺乏续航时。

### 4. 英雄（输出/清怪位/单排）

**机制**

- **主动技能「冲刺」**：向前冲刺，对命中异象造成120伤害，命中数决定淬锋层数。充能2/3次，单次40秒，冲刺期间免疫绝大多数伤害和控制。
- **被动「淬锋」**：每通过移动或跳跃消耗13点体力，提升下次武器攻击25%伤害，最多叠3层；仅第一段伤害享受加成。
- **被动「击杀回体」**：击杀异象恢复40点体力。

**操作要点**

- 磷光症地图独狼玩家的首推职业：输出够，清怪快，遇到怪群有一战之力而不是只能逃跑。
- 冲刺期间免伤，可用于规避高威胁异象的关键技能（如无光的残影冲刺、夜莺的坠击）。
- 淬锋层数需要靠移动/跳跃积累，赶路时保持跳跃可以顺带叠层，接敌时第一刀伤害更高。

**适用人群**：独狼玩家、喜欢正面清怪推进的玩家。

## 二、监管者阵营

### 模式通用机制（优先掌握）

监管者模式与求生者模式规则差异较大，理解通用规则比研究单个角色更重要。

**基础规则**

- 每周免费7次，周一零点刷新；用完后消耗辞章「添页」进入（求生者模式掉落）。
- 支持单人/双人组队，目前开放普通与困难难度。
- 开局自带监管者专属武器，位于底部道具栏，**不可卸下**。
- 监管者自带体力与移速强化，且**无下蹲键**，无法通过下蹲躲避鹿头钩子。
- 普攻为范围伤害，可一次命中多个目标；击杀怪物可回血（量较少，仍需带针）。

**AI求生者机制**

- 地图中刷新AI操控的配角求生者，会抢夺辞章、开古董柜。
- **拖尾颜色判断携带品质**：白色=空身，蓝色/紫色/金色对应辞章品质，品质越高拖尾越明显、持续越长。
- 攻击**正在开柜或翻板的AI**触发恐惧震慑，额外多打一段伤害。
- AI会攻击监管者，但伤害较低。

**辅助特质选择**

| 特质 | 效果                      | 推荐场景               |
|------|---------------------------|------------------------|
| 强袭 | 丢书稿造成伤害+眩晕       | 需要控制时             |
| 窥踪 | 感知辞章/容器，看异象轮廓 | **首选**，搜刮效率核心 |
| 显影 | 亮36米内AI轮廓20秒        | 专门抓人机时           |

**操作要点**

- 监管跳跃手感滞涩，跳二楼需提前掐距离，诛仙台不建议跳。
- 使用嗅盒时**不要跳跃**，否则容易中断。
- 蓄力刀和冲刺是打精英怪的主要手段，冲刺可赶路且不消耗体力，CD恢复快。
- 监管出刀几乎无后摇，空刀不擦刀，手感接近“人均狂想曲”。

### 首批可用监管者与选择建议

首批开放14位：**厂长、小丑、鹿头、“杰克”、蜘蛛、红蝶、黄衣之主、宿伞之魂、摄影师、疯眼、梦之女巫、爱哭鬼、孽蜥、红夫人**。

**推荐选择**

- **红夫人**：轻击手感好，适合快速清怪和搜刮节奏。
- **梦之女巫 / 摄影师**：提升搜刮物资和找人效率的优先选项。
- **避免高体型屠夫**：体型过高会导致移速偏慢，即使使用加速道具也跑不快。

## 三、通用配装与避坑

| 普通针    | 1      | 回血                                    |

### 监管者配装

- **烟炉**带在手里，避免被异象打成大残。
- **两根针**必备，击杀回血量不足以维持健康血线。
- 富余格子带窥踪相关道具或应急品。

### 关键避坑

| 场景             | 操作                                               |
|------------------|----------------------------------------------------|
| 监管遇鹿头       | **无下蹲键**，只能靠跳跃/走位躲钩，不要站桩        |
| 监管被叹息球靠近 | 气球无法缠绕监管，靠近直接爆炸，提前拉开           |
| AI开柜时         | 立刻冲过去打震慑，收益高于自己开箱                 |
| 独狼进磷光症深层 | 从表层逐层下探，不要一进去就冲最深处               |
| 手电/提灯使用    | 只在需要确认前方时开，平时关灯摸黑走，避免暴露位置 |
