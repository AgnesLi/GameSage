## 五、获取与使用要点

### 辞章的核心用途

1. **变卖为墨迹**：绝大多数辞章可直接出售，换取专属货币“墨迹”，用于藏品系统抽取武器外观、时装、家具等。
2. **任务提交**：部分辞章是赛季任务的必需提交品，如信纸堆、相框、鬼娃娃、银质夜莺烛台等。未完成对应任务时，碰到必捡，优先级高于墨迹价值。
3. **武器洗练**：弧光类辞章是洗练庇护者之杖的材料。
4. **特殊交互**：鬼玺可召唤阴兵；缪斯的秘密可开启密室。

### 背包负重提醒

辞章有重量设定，中负重（约45）、重负重（约55）、超重（约70）会逐级降低移速。不要只盯着高价值重物，紫钻戒指、勺子这类轻量辞章在补额度时更划算。

### 箱子产出规律

- 普通木箱、小瓷瓶：可出金色辞章，包括孤光、金杯、金汤勺等
- 上锁古董柜：必定产出奇珍及以上品质
- 上锁精致柜（困难+）：必定产出稀世及以上品质
