# 第五人格「加页手记」全异象机制与打法攻略

> 适用模式：加页手记（摸金玩法）｜涵盖基础异象、联动异象及“磷光症”地图新增异象

## 一、基础杂兵类

### 1. 笨拙的盗匪

**机制**：移速极慢，仅会近身平A，血量极低，无范围伤害。击败后掉落“破裂的木板”（价值2000墨迹）。

**打法**：蓄力一刀直接带走，平A两下解决。多只围堵时找柱子卡视野逐个击破。赶路时嫌麻烦可直接冲刺脱离仇恨，不耽误搜点。

### 2. 贪婪的盗匪（白锤/绿锤）

**机制**：分白锤与绿锤两种形态。白锤单次跳跃砸击，范围伤害约25点，前摇明显；绿锤为二段蓄力跃击，命中附带僵直，伤害约40点，极易接后续连招致倒地。统一血量约3次平A击倒。

**打法**：怪物起跳瞬间向其身后跳跃，可完美躲开整片砸击范围。等落地硬直后蓄力突刺，补平A收尾。绿锤切忌正面硬接蓄力攻击，横向拉扯待其落地后再输出。多人局用墙体分割逐个处理。

## 二、精英威胁类

### 3. 镜中回忆

**机制**：镜子持续刷新幽灵鸟追击玩家，**只杀鸟不拆镜则无限重生**。幽灵鸟飞行方向指向镜子本体位置。

**打法**：进入房间第一时间找发光镜面，交互摧毁即彻底根除该异象。途中零星青鸟可抬视角空中平A击落，避免持续掉血。多镜子房间按就近顺序拆，室内角落镜子优先级最高。

### 4. 无名布偶 → 厄运替身

**机制**：初始状态仅尾随玩家并发出低频音效，无攻击性。长时间无视或主动攻击会进化为**厄运替身**，解锁冲刺撞击（伤害约30-40）与落地重压，输出翻倍。

**打法**：

- **安抚流**：靠近点击“抚摸”交互，短暂保持中立。
- **高台逃课流（推荐）**：跳上柜子、高台后再抚摸，布偶无法攀爬，永久丢失仇恨。
- **已变身厄运替身**：利用门框、墙体卡视野规避冲刺，等技能后摇输出。最佳方案仍是站高台白嫖伤害。约需4~5次平A或3次蓄力突刺击杀。

### 5. 叹息球

**机制**：控制类异象中最危险的存在。单只附着持续掉血；**两只同时附身触发浮空禁锢**，无法移动与攻击，只能等自爆，无队友必倒。击碎时产生小范围爆炸伤害。

**打法**：远距离发现气球立刻抬高视角远程击碎，打完立刻后撤规避爆炸。地下隐藏气球可用扫描道具提前探测。若不慎被双球附身，保持蹲姿等待自爆结束，落地第一时间使用恢复道具补血。

### 6. 失职的看守（鹿头）

**机制**：分为普通与高强度版本。核心技能为**远程勾索**（无法格挡，可打断传送类道具）与近身劈刀。踩地图夹子大概率召唤该异象。

**打法**：看到甩钩前摇**立刻下蹲**即可规避勾索。优先选择带拐角地形拉扯。低强度版本两次满蓄力加一次平A可击杀，高强度版本需额外补充输出。新手靠墙体反复拉扯消耗，熟练后可绕背提升效率。

### 7. 缄默的绅士

**机制**：全场强度最高但**不主动攻击**。只要在其房间保持静步（行走模式）、不奔跑、不攻击、不使用道具，即为中立单位。可丢弃杂物与其交换物资。其他异象攻击你时，绅士会主动清理小怪。

**注意**：一旦被激怒，其连续平A伤害极高（约35点/段，连击可达70）。不慎激怒需拉远距离用蓄力突刺应对，不建议正面硬刚。

## 三、联动异象：阴兵（盗墓笔记联动）

### 8. 号角阴兵

**机制**：自身攻击力极弱，但能大范围感知移动目标并**吹号召集全楼层异象**向目标位置聚拢，同时为旗杆阴兵附加攻速与移速增益。血量较低。

**打法**：**必须优先集火清除**。使用“被遗忘的信仰”蓄力两刀即可击倒。若距离较远需控制移动，避免提前触发吹号。遭遇号角+旗杆组合时，找角度用蓄力范围伤害同时命中，绝不可先打旗杆阴兵。

### 9. 旗杆阴兵

**机制**：主要输出单位，**无法识别静止目标**，仅对移动中的玩家产生仇恨。攻击模式为三段连续突刺接冲刺攻击，伤害递增，冲刺判定距离远。

**打法**：单独遭遇时立刻**停止所有移动**，待仇恨消散后缓慢离开。必须正面作战时，在其突刺前摇出现时横向拉开，利用攻击间隔衔接蓄力攻击。约需三刀蓄力击败，预留一次格挡应对闪避失误。

**鬼玺机制**：阴兵借道叙事触发时，地图边角刷新绿色荧光房间，可获取鬼玺。持有鬼玺可召唤己方阴兵作战，并让野生阴兵暂时臣服。注意：
**召唤后必须一直手持鬼玺**，切换手持物己方阴兵会反过来攻击你。

## 四、“磷光症”地图新增异象

### 10. 磷光遗骸

**机制**：举石镐的结晶木偶，劈砍攻击，攻低血低。身上有光点，光点未亮起前可用提灯照射使其不再复活。

**打法**：直接击杀即可。若想节省体力，趁光点未亮时用提灯照射，可避免其复活，专心探索。

### 11. 磷焰矿灯

**机制**：结晶翅膀的飞行提灯，喷火/吐气/追踪激光，单次伤害低但持续伤害高，血量较多。**提灯照射可使其不攻击你**，但存在多个怪物时该方法无效。

**打法**：单只时用提灯照射规避战斗。多只时优先拉远距离逐个处理，避免被持续灼烧消耗。

### 12. 拟形的排演者

**机制**：被丝线操纵的瘦长木偶，向前挥打或连续踢腿三次，血量较多。

**打法**：趁其攻击后摇输出，反复拉扯即可击败。不要在其连踢期间贴近。

### 13. 无光的残影

**机制**：多肢体虫状人体，**向前连续冲刺六次**，攻高血极高，威胁极大。**提灯照射可将其控制**。

**打法**：优先提灯照射控住再攻击。无提灯时极难正面对抗，建议绕路或利用高低差规避。

### 14. 守财木偶

**机制**：不会攻击玩家，但会**偷走背包中的辞章**，移动速度快。逃跑途中会自己摔倒。

**打法**：追逐等待其摔倒后攻击，即可拿回被偷辞章。无需提前击杀，但辞章价值高时建议优先处理。

### 15. 读者的审视

**机制**：角色脚下出现黑圈，约3秒后黑手笼罩控制并造成伤害。**仅能通过移动躲避，无法反击**。

**打法**：看到脚下黑圈立刻持续跑动，直到黑手落下。不要停下试图攻击，该异象无法被常规手段反制。

### 16. 读者的揣摩

**机制**：多个小黑球组成的异象，要求玩家观看其演出。若拒绝或远离则遭受高频低伤攻击，血量较多。

**打法**：拉远距离后使用武器冲刺攻击，避免在其演出判定范围内缠斗。

## 五、特殊/高难异象

### 17. 倾颓书架（噩梦难度）

**机制**：血量极高（约2000），直接攻击本体书闭合时伤害极低。**必须攻击“翻开的书页”**才能打出十倍伤害。书架会追击并发动桌腿钻击、书页射击、跳砸冲击波（均约35伤害）。

**打法**
：引至古董柜、桌子等有高度的家具旁，跳上家具再跳到书架桌面——站上瞬间书本自动翻开，立刻攻击翻开的书，两下即可击杀。攻击一次后会被弹落，重复上述流程2~
3次即可。

### 18. 夜莺/灾厄之女（噩梦难度限定）

**机制**：出现在“灾厄之女-结局区域”（缪斯像房间墙壁画后进入）。攻击包括前方二连击、范围落下攻击（可穿障碍物）等。血量过半进入第二形态，攻击强化。

**核心打法**：

- 将夜莺的攻击**引向石柱**，击碎石柱后鸟笼掉落金色鸟。**不要立刻击杀金鸟**，保留至夜莺半血以下或残血时再击破，可造成大额伤害甚至跳过第二形态。
- 诱导夜莺至板区，用板砸中可造成伤害并使其短暂胆怯。
- 非范围攻击可躲在石柱/墙壁后规避。夜莺移至中央时是使用急救针回复的最佳窗口。

## 六、通用避坑要点

| 场景           | 关键操作                                         |
|----------------|--------------------------------------------------|
| 被双叹息球附身 | 蹲下等自爆，落地立刻回血，不要挣扎移动           |
| 失职的看守甩钩 | **下蹲**，不是闪避也不是格挡                     |
| 旗杆阴兵追击   | **停住不动**，它只打移动目标                     |
| 缄默的绅士房间 | 切**行走模式**，不跑不攻击不丢道具               |
| 无名布偶尾随   | 跳上高台后再抚摸，永久脱仇                       |
| 镜中回忆       | 鸟来的方向 = 镜子位置，先拆镜再清鸟              |
| 磷光症地图     | **提灯必带**，克制磷光遗骸、磷焰矿灯、无光的残影 |

---

> **总结**
> ：加页手记的异象设计核心在于“机制识别优先于数值碾压”。杂兵可速杀，精英需拆机制，控制类（叹息球）和控制型精英（失职看守）优先规避而非硬刚。缄默绅士与旗杆阴兵存在“非战斗解法”，善用可大幅节省资源。磷光症地图中提灯是核心克制道具，噩梦难度下的倾颓书架与夜莺则需要专门的手法练习。
